## Tentang proyek
- Proyek ini memakai Node.js dan kebanyakan file berekstensi .js.
- Cek file `package.json` untuk melihat perintah yang tersedia di bagian "scripts".
- Cara menguji: jalankan `npm test` kalau ada. Kalau tidak ada, jalankan file utamanya dengan `node namafile.js` dan lihat apakah ada error.
- Cara cek penulisan kode: `node --check namafile.js`.
